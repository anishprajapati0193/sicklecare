How the informational flags work

Reference thresholds are explicitly shown with any flags; they are educational prompts, not diagnostic criteria. Age, symptoms, setting, measurement quality, and clinician guidance can change interpretation. A value without a flag is not proof of health.

Privacy and data source

Records are stored in IndexedDB in this browser and are not sent to a server. No AI endpoint is configured; the displayed analysis is a local rule-based fallback. Do not place an API key in this page. This local prototype has no authentication, encryption, or access controls and is not suitable for production patient records. The 3D patch is visual only; saved values come from the user, never a sensor.
